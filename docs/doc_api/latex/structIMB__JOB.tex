\doxysubsection{Detailed Description}
Job structure.

For AES, enc\+\_\+keys and dec\+\_\+keys are expected to point to expanded keys structure.
\begin{DoxyItemize}
\item AES-\/\+CTR, AES-\/\+ECB and AES-\/\+CCM, only enc\+\_\+keys is used
\item DOCSIS (AES-\/\+CBC + AES-\/\+CFB), both pointers are used enc\+\_\+keys has to be set always for the partial block
\end{DoxyItemize}

For AES-\/\+GCM, AES-\/\+GCM-\/\+SGL and SM4-\/\+GCM, enc\+\_\+keys and dec\+\_\+keys are expected to point to the same key structure.
\begin{DoxyItemize}
\item enc\+\_\+keys is used for encrypt direction and dec\+\_\+keys for decrypt direction
\end{DoxyItemize}

For DES, enc\+\_\+keys and dec\+\_\+keys are expected to point to DES key schedule.
\begin{DoxyItemize}
\item same key schedule used for enc and dec operations
\end{DoxyItemize}

For 3DES, enc\+\_\+keys and dec\+\_\+keys are expected to point to an array of 3 pointers for the corresponding 3 key schedules.
\begin{DoxyItemize}
\item same key schedule used for enc and dec operations
\end{DoxyItemize}

Cipher offset only applies to src pointer, not dst pointer. In case of an in-\/place operation, dst pointer needs to point at src + cipher\+\_\+start\+\_\+src\+\_\+offset\+\_\+in\+\_\+bytes.
